## M365 Copilot future adaptation boundary

Do not create an M365 runtime adapter in v0.1.0. A future organisational-zone
adaptation may translate the stable workflow into agent instructions,
first-party knowledge, read-only actions, a controlled claim-register tool, and
evaluations. It must:

- remain inside organisational identity, DLP, audit, residency, and retention
  controls;
- use an allow-list of approved first-party sources;
- preserve atomic claims, evidence/release labels, and abstention;
- write only through an approved schema and consequential-action approval;
- never automatically synchronize tenant evidence to personal ChatGPT/Codex.

M365 Copilot is not a `SKILL.md` runtime merely because the methodology is
portable.

## Copilot Studio future adaptation boundary

Do not create a Copilot Studio runtime adapter in v0.1.0. A future
organisational-zone implementation may translate the workflow into
instructions, approved knowledge/tools, prompts, agent flows/workflows, DLP,
solution artifacts, and evaluation cases. It must reverify the target
experience and skill/runtime status, licensing, geography, security, and ALM
before implementation.

No tenant auth, agent creation, plugin installation, solution change, or cloud
sync is authorized by this document.
